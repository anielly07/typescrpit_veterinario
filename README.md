# Clínica veterinária

Projeto de exemplo em TypeScript com classes abstratas, herança e encapsulamento.

## Requisitos

- Node.js
- npm

## Como executar

```bash
npm install
npm run build
npm start
```

O exemplo cria tutores, animais, funcionários e consultas, lista os cuidados dos
animais e calcula os bônus dos funcionários.
